고등학교에 다니며 개인 서비스를 만들고 운영합니다. Next.js와 Supabase로 개발하고 Vercel에 배포합니다.

[홈페이지](https://sooyeol2g.com) · [이메일](mailto:sy@sooyeol2g.com)

## 대표 서비스

- **[파일 전송](https://transfer.sooyeol2g.com)** · 기기 간에 파일을 전송합니다.
- **[구독 관리](https://subs.sooyeol2g.com)** · 구독 내역을 한곳에서 관리합니다.
- **[과제연구 관리](https://lab.sooyeol2g.com)** · 과제연구를 정리하고 관리합니다.

## 기타 운영 사이트

| 서비스 | 용도 |
| :-- | :-- |
| [파일 뷰어](https://drive.sooyeol2g.com) | 파일 열람 |
| [인원 체크](https://bus.sooyeol2g.com) | 출발 전 인원 체크 |
| [활동 기록](https://archive.sooyeol2g.com) | 활동 아카이브 |
| [대체 접속](https://bypass.sooyeol2g.com) | 도메인 접속이 어려울 때 |

## 기술 스택

TypeScript · Next.js · React · Tailwind CSS · Supabase · Vercel
